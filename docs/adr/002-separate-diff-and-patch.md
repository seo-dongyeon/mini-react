# 002. Diff는 변경 목록을 만들고 Patch가 적용한다

- 상태: Accepted
- 날짜: 2026-11-07

## 맥락

두 Virtual DOM을 비교해 바뀐 부분만 실제 DOM에 반영해야 한다. 비교하면서 바로 DOM을 고치는 방식은 코드가 짧지만, 테스트할 때 실제 DOM이 필요하고 반영 전에 "무엇이 바뀌는지" 보여줄 수 없다.

## 결정

두 단계로 나눈다.

- `diff(oldVNode, newVNode)`는 DOM을 건드리지 않는 순수 함수다. `{ type, path, ... }` 형태의 변경 연산 목록을 반환한다. `path`는 루트에서 대상 노드까지의 자식 인덱스 배열이다.
- `patch(rootEl, ops)`는 연산 목록을 실제 DOM API로 적용한다.

과제의 "변경된 부분을 찾고 → 그 부분만 반영"과 구조가 같고, 실제 React도 변경 표시 단계와 DOM 반영 단계를 나눈다.

## 결과

- `diff`는 DOM 없이 입력 VNode와 출력 목록만으로 테스트할 수 있다.
- 연산 목록을 그대로 로그나 하이라이트에 쓸 수 있다.
- 연산 형식과 `path` 해석 코드가 추가된다. 한 번의 patch 안에서 앞 연산이 인덱스를 바꾸면 뒤 연산의 경로가 틀어질 수 있으므로, 적용 순서 규칙을 구현과 테스트로 고정해야 한다.
