# 004. 테스트 영역은 소스 textarea로 편집하고 입력을 정화한다

- 상태: Accepted
- 날짜: 2026-11-07

## 맥락

사용자가 테스트 영역의 샘플 HTML을 자유롭게 수정하고, Patch로 실제 영역에 반영해야 한다. contenteditable 화면 편집은 텍스트 외에 태그·속성을 바꾸기 어렵다. 사용자 입력 HTML을 실제 DOM에 넣으면 XSS(입력 속 스크립트 실행) 위험이 있다.

## 결정

- 테스트 영역은 HTML 소스 textarea로 한다. VDOM을 HTML 문자열로 바꿔 채우고, Patch 시 `<template>`로 파싱한 DOM을 VDOM으로 바꾼다. `<template>` 안의 내용은 화면에 그려지거나 실행되지 않는다.
- VDOM 변환 단계에서 아래를 제거하고 제거 사실을 화면에 알린다.
  - `script`, `iframe`, `object`, `embed` 태그
  - `on*` 이벤트 속성
  - `javascript:` URL
- 공백만 있는 텍스트 노드와 주석은 무시한다.

## 결과

- 태그·속성까지 자유롭게 수정할 수 있고, 엣지 케이스를 직접 입력해 시험할 수 있다.
- 렌더된 미리보기는 실제 영역이 대신한다.
- 정화 규칙은 차단 목록 방식이라 빠진 경로가 있을 수 있으므로 테스트로 보강한다.
